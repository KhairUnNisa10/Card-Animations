# Hover Card Animations

This project showcases **beautiful hover card animations** built with **HTML and CSS**.
Each card uses **linear gradients, blurred backgrounds, and smooth scaling effects** to create an eye-catching hover interaction.

The design is modern, minimal, and responsive, perfect as a component for portfolios, landing pages, or interactive UI elements.

## Features

* Gradient hover animations with scaling effects
* Responsive card layout with flexbox
* Customizable background styles (purple & pink variants included)
* Smooth hover transitions for a premium feel
* Built with pure **HTML & CSS** (no external frameworks)
